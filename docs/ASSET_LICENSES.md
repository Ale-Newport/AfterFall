# Asset sources and licenses

AFTERFALL currently ships **no third-party art, audio, fonts or models**. Every mesh, texture and material colour in the game is produced procedurally by project code at runtime.

| Asset | Location | Source | License |
|---|---|---|---|
| Procedural meshes (trees, rocks, roofs, props, characters) | generated by `Presentation/Rendering/MeshFactory.cs`, `PropBuilder.cs`, `NodeVisuals.cs`, `StructureVisuals.cs`, `HumanoidRig.cs` | Original project code | Project license |
| Procedural terrain textures and fog texture | generated by `WorldBuilder.cs`, `TacticalController.cs` | Original project code | Project license |
| UI stylesheet and theme (`Resources/UI/Afterfall.uss`, `AfterfallTheme.tss`) | `Assets/_Afterfall/Resources/UI` | Original. The theme file imports Unity's built-in default runtime theme (`unity-theme://default`) | Project license; Unity built-in theme under the Unity Editor terms |
| Base materials (`AfterfallLit`, `AfterfallTransparent`, `AfterfallEmissive`, `AfterfallWater`, `AfterfallTerrain`, `AfterfallUnlitTransparent`) | `Assets/_Afterfall/Resources/Materials` | Derived from `Lit.mat` / `TerrainLit.mat` in `com.unity.render-pipelines.universal` 17.3.0 (property values changed) | [Unity Companion License](https://unity.com/legal/licenses/unity-companion-license) |
| URP pipeline and renderer assets, volume profiles, global settings | `Assets/_Afterfall/Settings` | Unity 3D (URP) project template `com.unity.template.urp-blank` 17.0.14 shipped with Unity 6000.3.28f1 | Unity Companion License |
| ProjectSettings baseline | `ProjectSettings/*.asset` | Same template, customised (product name, layers, build scenes, shadow distance) | Unity Companion License |
| Main scene settings blocks | `Assets/_Afterfall/Scenes/Main.unity` | Template `SampleScene` settings blocks; objects authored for AFTERFALL | Unity Companion License |
| Unity packages | `Packages/manifest.json` (resolved by Unity) | Unity Package Manager registry | Unity Companion License or each package's own license |
| Newtonsoft.Json | via `com.unity.nuget.newtonsoft-json` and NuGet (tests) | James Newton-King | MIT |
| NUnit (headless tests) | NuGet | NUnit project | MIT |

Rules:
- Record every new third-party asset here **before** committing it: source URL, author, license, and any modifications.
- Track binary assets with Git LFS (`.gitattributes`).
- Do not add assets whose license forbids redistribution in a game, and do not add assets that copy existing games' characters, maps, UI or music.
