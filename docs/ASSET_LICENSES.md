# Asset sources and licenses

AFTERFALL's only third-party art is its **human characters**: fourteen skinned models made from MakeHuman's CC0 system assets, and two **motion-captured gait cycles** converted from the CMU Graphics Lab Motion Capture Database (below). Every other mesh, texture and material colour in the game is produced procedurally by project code at runtime.

Rules:
- Record every new third-party asset here **before** committing it: source URL, author, license, and any modifications.
- Track binary assets with Git LFS (`.gitattributes`).
- Do not add assets whose license forbids redistribution in a game, and do not add assets that copy existing games' characters, maps, UI or music.
